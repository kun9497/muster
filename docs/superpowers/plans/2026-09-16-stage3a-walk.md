# Stage 3A — The Deep Filesystem Walk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the stage-1 `walk` placeholder with the `--deep` filesystem walk of spec W-1…W-12 — a no-follow, mount-bounded, budgeted traversal that joins every candidate to the package database — and enrol U-15, U-23 and U-33 with four new controls so that every one of the 67 KISA items has a control (64 → 68 controls: auto 57, partial 7, manual 4) and U-25 judges a real host.

**Architecture:** One collector, three files: `walk_mounts.go` decides what is entered (mountinfo, the positive type list, bind aliases, container storage, the homes), `walk_traverse.go` walks it through a new `Access.ReadDir` primitive and sorts every entry into the six finding lists, `walk_join.go` looks the candidates up in rpm's file table or dpkg's `.list`/`statoverride`/reference-list stack after the traversal. The read primitive gains `ReadDir` (openNoFollow + fstat identity check + `statx` with `STATX_MNT_ID`) and `Readlink`; the guard gains a `Walk` licence; the evaluator gains `not_contains`; lint gains a `none`-needs-`subject` rule and a relaxed `kisa_coverage`. Reference lists for the dpkg family are an embedded Go package under `docs/reference/suid/`, generated by the maintainer tool `tools/suidindex`.

**Tech Stack:** Go 1.25, `golang.org/x/sys/unix` v0.36.0 (`Statx`, `Getdents`/`ParseDirent`, `Readlinkat`, `Setpriority`, raw `SYS_IOPRIO_SET`), the `fsAccess` test double, the lab host for the Linux-only suite (root, non-root and a `setpriv`-reduced root run), GitHub Actions (`.github/workflows/ci.yml`). No new Go dependency (D28).

**Spec:** `docs/superpowers/specs/2026-09-16-stage3a-walk-design.md` (W-1…W-12; §2 traversal, §3 candidates, §4 join, §5 controls, §6 flags, §7 errors, §8 tests, §9 what changes elsewhere) and the main design `docs/superpowers/specs/2026-09-02-muster-design.md` (§5.8 truncation, §6.5 rows 6/7/9/10/10a, §8 reads and commands). Both are committed on this branch at `9361494`.

- **Ruling A-2 (the primitive's signature, W-3):** `Access.ReadDir(p string, expect Identity) (Listing, error)`. `Identity{Dev, Ino uint64}`; a zero `expect` skips the identity check (the walk's roots); a mismatch returns `ErrVanished`. `Listing{Self DirEntry; Entries []DirEntry}` — `Self` is the directory's own `statx` (its `MntID` is what the walk enters with), `Entries` are sorted by `Name` by the primitive itself so determinism is settled at the source. `DirEntry{Name, Kind string; Mode uint32; UID, GID uint32; Dev, Ino, MntID uint64; MntIDKnown bool; Size int64}`, `Kind` from the existing `kindOf`, `Mode` the raw `st_mode & 07777`. An entry that vanishes between `getdents` and `statx` (ENOENT) is dropped from the listing; every other `statx` error on an entry is returned as the listing's error. `Access.Readlink(p string) (string, error)` reads the link at `p` through the parent opened no-follow (`Readlinkat`) and is guarded by `Declaration.Reads` like `Stat`.

- **Ruling A-15 (`walk.skipped` rows, §2):** a row is `{path, reason, detail}`. `reason` is exactly one of `excluded_type`, `pseudo_path`, `container_storage`, `excluded_by_flag`, `bind_duplicate`, `denied`, `vanished`, `unlisted_mount`; `detail` is `""` except: the fstype for `excluded_type`, the symlink's own path for a `container_storage` root reached through `Readlink`, the configuration file for a configured root, and the errno text for a `vanished` row that came from an errno outside ENOENT/ENOTDIR/ELOOP (EIO, ENAMETOOLONG, ENOMEM are `vanished` with the errno in `detail`, so the vocabulary stays closed and nothing is lost).

func (hostAccess) ReadDir(p string, expect Identity) (Listing, error) {
	fd, _, err := openNoFollow(rewriteProcSelf(p), unix.O_RDONLY|unix.O_DIRECTORY|unix.O_NOFOLLOW|unix.O_CLOEXEC)
	if err != nil { return Listing{}, err }
	defer unix.Close(fd)
	self, err := statxAt(fd, "", unix.AT_EMPTY_PATH|unix.AT_SYMLINK_NOFOLLOW|unix.AT_NO_AUTOMOUNT)
	if err != nil { return Listing{}, err }
	if expect != (Identity{}) && (self.Dev != expect.Dev || self.Ino != expect.Ino) {
		return Listing{}, fmt.Errorf("%s: %w", p, ErrVanished)
	}
	names, err := readNames(fd) // unix.Getdents in a 64 KiB buffer loop + unix.ParseDirent; "." and ".." dropped
	if err != nil { return Listing{}, err }
	sort.Strings(names)
	out := Listing{Self: self}
	for _, n := range names {
		e, err := statxAt(fd, n, unix.AT_SYMLINK_NOFOLLOW|unix.AT_NO_AUTOMOUNT)
		if errors.Is(err, unix.ENOENT) { continue } // vanished between getdents and statx
		if err != nil { return Listing{}, fmt.Errorf("%s/%s: %w", p, n, err) }
		e.Name = n
		out.Entries = append(out.Entries, e)
	}
	return out, nil
}

func statxAt(dirfd int, name string, flags int) (DirEntry, error) {
	var st unix.Statx_t
	if err := unix.Statx(dirfd, name, flags, unix.STATX_BASIC_STATS|unix.STATX_MNT_ID, &st); err != nil {
		return DirEntry{}, err
	}
	return DirEntry{
		Kind: kindOf(uint32(st.Mode)), Mode: uint32(st.Mode) & 0o7777, UID: st.Uid, GID: st.Gid,
		Dev: unix.Mkdev(st.Dev_major, st.Dev_minor), Ino: st.Ino,
		MntID: st.Mnt_id, MntIDKnown: st.Mask&unix.STATX_MNT_ID != 0, Size: int64(st.Size),
	}, nil
}

func (hostAccess) Readlink(p string) (string, error) {
	p = rewriteProcSelf(p)
	if !path.IsAbs(p) || path.Clean(p) != p || p == "/" { return "", fmt.Errorf("path %q must be absolute and clean", p) }
	dir, _, err := openNoFollow(path.Dir(p), unix.O_PATH|unix.O_DIRECTORY|unix.O_NOFOLLOW|unix.O_CLOEXEC)
	if err != nil { return "", err }
	defer unix.Close(dir)
	buf := make([]byte, unix.PathMax)
	n, err := unix.Readlinkat(dir, path.Base(p), buf)
	if err != nil { return "", fmt.Errorf("%s: %w", p, err) }
	return string(buf[:n]), nil
}
