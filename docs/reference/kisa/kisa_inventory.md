### 1.3 추출 방법

- 다운로드: `curl` + 브라우저 User-Agent + Referer (KISA 사이트는 `/post/fileDownload` 엔드포인트를 사용하며, 파라미터는 `/resource/kor/js/common.js` 의 `fnPostAttachDownload()` 정의에서 확인).
- 텍스트 추출: Python `pypdf` 6.16.2. **두 PDF 모두 한글 텍스트가 정상적으로 추출**되었으며 OCR이나 페이지 이미지 판독은 불필요했다.
- 2021년판에는 일부 글리프 아티팩트(`/square6` = 글머리표, 자간 깨짐)가 있으나 항목명·항목코드·중요도 판독에는 영향이 없었다.

### 1.4 페이지 번호 기준

- **2026년판**: 인쇄 페이지 번호 = PDF 페이지 인덱스 (예: PDF 12쪽에 "12" 인쇄). 본 문서의 `page` 값은 두 기준이 동일.
- **2021년판**: 인쇄 페이지 번호 = **PDF 페이지 인덱스 − 8**. 본 문서/JSON의 `page` 값은 **인쇄 페이지 번호**이다 (PDF 뷰어에서 열 때는 +8). 이 오프셋은 목차(PDF 4쪽)의 각 절 시작 페이지와 본문 실제 위치를 대조하여 검증했다 (예: 목차 "1. 계정 관리 … 기본 5" ↔ U-01 본문 PDF 13쪽).

- 2021년판 72개 항목 중 **63개**가 2026년판 Unix 항목으로 매핑, **9개**가 제외(웹 서비스 장 이관 8개 + 삭제 1개) → 63 + 9 = 72 (전수 일치, 스크립트 assert로 검증).

## 6. 주요 변경점 (요약)

1. **번호 체계가 전면 재배열되었다.** 2021년판은 "기본 항목 U-01~U-43 + 선택 항목 U-44~U-72"를 분류별로 섞어 배치했으나, 2026년판은 기본/선택 구분을 없애고 분류 순서대로 U-01~U-67을 연속 부여했다. 그 결과 **항목코드가 동일하면서 의미도 같은 항목은 U-01, U-03, U-04 단 3개뿐**이다. 예를 들어 U-05는 2021년 "root 홈, 패스 디렉터리 권한 및 패스 설정" → 2026년 "root 이외의 UID가 '0' 금지"로 완전히 다른 항목을 가리킨다. **판본을 구분하지 않고 U-xx를 사용하는 코드는 반드시 오작동한다.**
2. **웹서비스 점검이 Unix에서 분리되었다.** 2021 U-35~U-41(웹서비스 7개) 및 U-71(Apache 정보 숨김)이 Unix 항목에서 빠지고, 2026년판에 `III. 웹 서비스` 장(WEB-01~WEB-26)이 신설되었다.
3. **비밀번호 정책 4개 항목이 1개로 통합되었다.** 2021 U-02(복잡성)+U-46(최소 길이)+U-47(최대 사용기간)+U-48(최소 사용기간) → 2026 **U-02 "비밀번호 관리정책 설정"**.
4. **8개 항목이 신설되었다.** U-13(안전한 비밀번호 암호화 알고리즘), U-51(DNS 동적 업데이트), U-53(FTP 서비스 정보 노출), U-59(안전한 SNMP 버전), U-61(SNMP Access Control), U-63(sudo 명령어 접근 관리), U-65(NTP 및 시각 동기화), U-67(로그 디렉터리 소유자 및 권한).
5. **2개의 통합이 추가로 발생했다.** cron+at → U-37, NFS 접근통제+NFS 설정파일 접근제한 → U-40.
6. **벤더 종속 명칭이 일반화되었다.** Sendmail → "메일 서비스"(U-45, U-46), Anonymous FTP → "공유 서비스에 대한 익명 접근 제한"(U-35), "ssh 원격접속 허용" → "Telnet 서비스 비활성화"(U-52, 관점 반전).
7. **중요도가 조정된 항목이 있다.** 예: 관리자 그룹 최소 계정(하→중), 정책에 따른 시스템 로깅 설정(하→중).

## 7. 신뢰도 및 유의사항 (Confidence and caveats)

### 7.1 PDF에서 직접 검증한 사항 (confidence: **high / primary**)

- 두 PDF 모두 KISA 공식 사이트(`kisa.or.kr`)에서 직접 내려받았으며 SHA-256을 위에 기재했다. 2차 출처에 의존한 부분은 없다.
- **2026년판 67개 항목 전부**의 항목코드·항목명·중요도·분류·시작 페이지: 8~11쪽 항목표와 12~171쪽 본문 러닝헤더(`U-NN / (중요도) / UNIX > N. 분류 / 항목명`) **양쪽에서 각각 추출하여 상호 대조**했다. U-01~U-67이 빠짐없이 연속 확인되었다.
- **2021년판 72개 항목 전부**의 항목코드·항목명·중요도·분류·시작 페이지: 11~12쪽 항목표와 본문 러닝헤더(`U-NN (중요도) N. 분류 > N.N 항목명`)에서 각각 추출하여 대조했다. U-01~U-72 전부 확인.
- 분류 경계(어느 항목이 어느 분류인지): 항목표뿐 아니라 **본문 러닝헤더의 분류명**으로 항목별 개별 확인했다. 2026년판 항목표는 2단 조판이라 텍스트 추출 시 분류 제목이 어긋난 순서로 나오는데, 본문 러닝헤더 대조로 이를 교정했다.
- 페이지 번호 오프셋(2021년판 −8)은 목차의 절 시작 페이지와 본문 위치를 9개 지점에서 대조하여 검증했다.
- 다음 매핑은 **본문 내용으로 확증**했다 (항목명 유사성만이 아님):
  - U-02 통합 — 참고와 조치 방법이 비밀번호의 복잡성·길이·사용 기간·재사용 제한을 하나의 정책으로 묶어 다룬다.
  - U-37 통합 — 점검 내용과 판단 기준이 cron 관련 파일과 at 관련 파일의 권한을 함께 다룬다.
  - U-40 통합 — 판단 기준이 NFS 접근 통제 설정 여부와 NFS 설정 파일의 접근 권한을 함께 요구한다.
  - U-35 ← 2021 U-20 — 점검 및 조치 사례가 익명 FTP(`userdel ftp`, `anonymous_enable`) 중심.
  - U-53 신설 — FTP 접속 배너(`ftpd_banner`) 설정을 보는 점검으로 2021년판에 대응 항목 없음.
- 대부분의 `renumbered` 매핑은 항목명이 사실상 동일하고 **점검 내용이 다루는 대상까지 일치**함을 두 PDF에서 각각 확인했다.

### 7.2 추론에 의존한 사항 (confidence: **medium — 검토 필요**)

- **U-17 시스템 시작 스크립트 권한 설정** ← U-14 (`split`): [불확실] 2021 U-14 '사용자, 시스템 시작파일 및 환경파일 소유자 및 권한 설정' 중 시스템 시작파일에 해당하는 부분이 독립 항목이 된 것으로 추정. 다만 PDF 대조 결과 2026 U-17의 점검 내용은 시작 스크립트의 권한만 다루고 2021 U-14 쪽은 환경변수 파일 위주여서 서술이 직접 겹치지는 않으므로 'new'로 볼 여지도 있음
- **U-52 Telnet 서비스 비활성화** ← U-60 (`renumbered`): [주의] 관점이 반전됨. 2021 U-60 'ssh 원격접속 허용'은 원격 접속에 SSH를 쓰는지를 보고, 2026 U-52 'Telnet 서비스 비활성화'는 평문 Telnet이 열려 있는지를 본다. 동일 리스크를 서로 반대 방향에서 기술한 것으로 판단

제외 항목 중 다음은 **2026년판 웹 서비스 장 항목표(272~273쪽)의 항목명만 보고 대응 관계를 추정**한 것으로, WEB-xx 본문 내용까지 대조하지는 않았다. Unix 항목(U-xx)에서 빠졌다는 사실 자체는 확실하다:

- **U-35 웹서비스 디렉토리 리스팅 제거** → 2026 신설 'III. 웹 서비스'(WEB-01~WEB-26) 장으로 이동. WEB-04 '웹 서비스 디렉터리 리스팅 방지 설정'에 대응하는 것으로 추정(항목명 기준, 본문 대조 미수행)
- **U-36 웹서비스 웹 프로세스 권한 제한** → WEB-09 '웹 서비스 프로세스 권한 제한'에 대응 추정
- **U-37 웹서비스 상위 디렉토리 접근 금지** → WEB-06 '웹 서비스 상위 디렉터리 접근 제한 설정'에 대응 추정
- **U-38 웹서비스 불필요한 파일 제거** → WEB-07 '웹 서비스 경로 내 불필요한 파일 제거'에 대응 추정
- **U-39 웹서비스 링크 사용 금지** → WEB-12 '웹 서비스 링크 사용 금지'에 대응 추정
- **U-40 웹서비스 파일 업로드 및 다운로드 제한** → WEB-08 '웹 서비스 파일 업로드 및 다운로드 용량 제한'에 대응 추정
- **U-41 웹서비스 영역의 분리** → [불확실] WEB-11 '웹 서비스 경로 설정' 또는 WEB-14 '웹 서비스 경로 내 파일의 접근 통제'에 대응 추정
- **U-43 로그의 정기적 검토 및 보고** → 2026 Unix 로그 관리(U-65~U-67)에 대응 항목 없음. 관리적 점검 영역으로 이관된 것으로 추정되나 별도 '관리·물리적 취약점 분석·평가 방법 안내서'는 미확인
- **U-71 Apache 웹 서비스 정보 숨김** → [불확실] WEB-16 '웹 서비스 헤더 정보 노출 제한' 또는 WEB-22 '에러 페이지 관리'에 대응 추정

### 7.3 원본 PDF의 편집 오류 (구현 시 주의)

- **2026년판 U-26 (53쪽, `/dev에 존재하지 않는 device 파일 점검`)** — `점검 내용`과 `점검 목적` 두 칸에 접속 IP·포트 제한을 설명하는 서술이 들어가 있다. 이는 **U-28(접속 IP 및 포트 제한)의 본문이 잘못 복사된 것**이며, 같은 항목의 항목명·보안 위협·참고·판단 기준·조치 방법은 모두 정상적으로 `/dev` device 파일 내용이다. 텍스트 추출 오류가 아니라 **배포된 PDF 자체의 오류**다.
- **2021년판 파일 및 디렉터리 관리 절 번호에 결번이 있다.** U-55가 `2.15`, U-56이 `2.17`로 `2.16`이 건너뛰어져 있다. 누락된 항목이 있는 것이 아니라 조판상 번호 오류이며, 항목표의 항목 수(72개)와 본문 항목 수는 일치한다.
- 2021년판 본문 러닝헤더에는 자간이 깨진 표기가 있다(예: U-72 "정 책에 따 른 시스템 로 깅 설정"). JSON의 `name_ko`에는 **항목표(11~12쪽)의 정규 표기**를 사용했다.

### 7.4 판본 간 항목명 표기 차이 (2026년판 내부)

2026년판은 8~11쪽 항목표와 본문 러닝헤더의 표기가 몇 군데 미세하게 다르다. JSON에는 **항목표 표기**를 채택했다(연속 공백은 1칸으로 정규화).

| 항목코드 | 항목표 (채택) | 본문 러닝헤더 |
|---|---|---|
| U-11 | 사용자 Shell 점검 | 사용자 shell 점검 |
| U-31 | 홈 디렉토리 소유자 및 권한 설정 | 홈디렉토리 소유자 및 권한 설정 |
| U-50 | DNS Zone Transfer 설정 | DNS ZoneTransfer 설정 |
| U-53 | FTP 서비스 정보 노출 제한 (원문은 "노출"과 "제한" 사이 공백 2칸 — JSON에서 1칸으로 정규화) | FTP 서비스 정보 노출 제한 |
| U-55 | FTP 계정 Shell 제한 | FTP 계정 shell 제한 |

2021년판도 마찬가지로 항목표 표기를 채택했다. 예: U-44는 항목표에 "root 이외의 UID가 '0'금지"(‘0’ 뒤 공백 없음)로 인쇄되어 있어 그대로 두었다.

### 7.5 확인하지 못한 사항

- 2026년판 이후의 추가 개정판이나 정오표가 있는지는 확인하지 않았다. 2026년판이 KISA 자료실(`2060204`) 게시판의 최신 기술적 상세가이드임은 목록 조회로 확인했다 (2025-12-24 등록, postSeq=22).
- 2021년판 U-43(로그의 정기적 검토 및 보고)이 "주요정보통신기반시설 관리·물리적 취약점 분석·평가 방법 안내서"(postSeq=23, 2025-12-24)로 이관되었는지는 **해당 안내서를 확인하지 않았으므로 추정**이다.
- Unix 이외 분야(Windows, DBMS, 네트워크 장비 등)의 항목은 본 조사 범위 밖이다.
